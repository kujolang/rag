# Release v0.1.0

## Summary

Initial versioned release process baseline for Kujo RAG.

## Changes

- Added deterministic release artifact generation script.
- Added release artifact CI workflow and checksum outputs.
- Added rollback-safe release process documentation.

## Validation Evidence

- `kujo run tests/test_release_artifacts.kujo --interpreter`
- `kujo run scripts/run_release_evaluation.kujo --interpreter`
- `kujo run scripts/run_tests.kujo --interpreter`

## Rollback Notes

Rollback is supported to previous patch/minor releases when compatibility markers match:

- `config_schema_version`
- `api_contract_version`

## Compatibility Notes

- `config_schema_version`: 1
- `api_contract_version`: 1
