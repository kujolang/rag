# RAG 1.1.0

This release expands local ingestion and retrieval with negotiated HTTP document formats, equivalent documentation example selection, response/context measurements, and a local published Kujo documentation snapshot/service workflow.

It also includes atomic index persistence, stricter parser and resource boundaries, privacy/export controls, descriptor-relative file ingestion, staged Qdrant recovery/rollback, and a Cloudflare Access proxy with trusted identity and RBAC enforcement.

Use Kujo 1.2.3 or newer. The default local workflow uses hash embeddings and local JSON storage. This package release does not certify an arbitrary hosted deployment, live AI provider, Qdrant service, or external audit sink. Those require their own target-environment credentials, staging/rollback rehearsal and production security attestation described in `docs/release-process.md` and `docs/production-security-attestation.md`.
