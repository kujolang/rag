# RAG 1.1.0

RAG 1.1.0 expands documentation retrieval and strengthens ingestion, authentication and recovery workflows.

## What’s new

- HTTP documentation ingestion and equivalent-example selection.
- Published-documentation snapshots and a managed documentation query service.
- Hardened structured ingestion, atomic index persistence and descriptor-relative path handling.
- Improved authentication, recursive error redaction and Cloudflare proxy boundaries.
- Verified index recovery, rollback and staged Qdrant recovery workflows.

## Compatibility

Requires Kujo 1.2.3 or newer. Associated JavaScript tooling requires a supported patched Node branch (22.23.4+, 24.22.1+, or 26.12.1+). API and configuration schema compatibility markers are unchanged.

Offline hash embeddings and JSON storage remain the defaults. Provider, remote-backend and deployment configuration is documented in the repository.

## Verification

The release passes the runtime support matrix, API and SDK contracts, security regression tests, recovery exercises, supply-chain scans and technical release gates. Release assets include a file manifest, SHA-256 checksums and a CycloneDX SBOM.
