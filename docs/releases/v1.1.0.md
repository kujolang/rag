# RAG 1.1.0

Adds HTTP documentation ingestion, equivalent-example selection and a local published-docs snapshot/service workflow. This release also hardens structured ingestion, index persistence, descriptor-relative paths, authentication, Cloudflare proxy boundaries and staged Qdrant recovery/rollback.

Requires Kujo 1.2.3 or newer. Associated JavaScript tooling requires a supported patched Node branch (22.23.4+, 24.22.1+, or 26.12.1+). API and configuration schema compatibility markers are unchanged.

Offline hash embeddings and local JSON storage remain the defaults. Live AI providers, remote vector backends and production deployments still require their documented configuration and target-environment checks. Publishing these source artifacts does not promote any deployment or renew production security attestations.
