# Release v1.0.0

Kujo RAG 1.0 is the stable local-first release of the ingestion, retrieval,
namespace-isolation, and HTTP API surfaces. Offline hash embeddings and the
local JSON vector backend remain the safe defaults; live providers and remote
vector backends require explicit configuration and target-environment review.

The release includes deterministic unit and integration coverage, OpenAPI and
SDK contract checks, release-evaluation gates, security controls, operational
documentation, and guarded ingestion paths.
