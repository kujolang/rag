# Migration Notes

This directory stores migration notes for releases that include breaking API or configuration changes.

## Migration Notes for Breaking Changes

Create one file per release:

- `docs/migrations/vX.Y.Z.md`

Required sections:

1. Summary of breaking changes
2. Compatibility impact
3. Upgrade steps
4. Rollback constraints
5. Validation checklist

Use `docs/migrations/v2.0.0-template.md` as the baseline template.
